# Combat Extended

### A complete combat system overhaul for RimWorld

Combat Extended replaces RimWorld's entire combat system with a realistic simulation featuring projectile physics, ammunition, cover mechanics, and tactical depth that transforms every battle into a serious engagement.

<br>

---

## Features

| | |
|:---|:---|
| **Projectile Physics** | Bullets travel in realistic arcs and can penetrate cover and bodies |
| **Ammunition System** | Pawns must carry and manage multiple ammunition types for each weapon |
| **Loadout System** | Assign specific equipment loadouts to every colonist and soldier |
| **Tactical Depth** | Flanking, suppression, and positioning matter far more than before |
