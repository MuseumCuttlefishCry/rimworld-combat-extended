| **Feature** | **Description** |
|:---|:---|
| **Projectile Physics** | Bullets travel in realistic arcs and can penetrate cover and bodies |
| **Ammunition System** | Pawns must carry and manage multiple ammunition types for each weapon |
| **Loadout System** | Assign specific equipment loadouts to every colonist and soldier |
